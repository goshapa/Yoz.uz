# Yoz

Fikringni yoz — «Напиши своё мнение». Социальная сеть коротких публикаций для аудитории Узбекистана.

Полное ТЗ: [Yoz_TZ(1).md](Yoz_TZ(1).md).

Текущий этап реализации: **весь объём первой версии из раздела 14 ТЗ**.

- Аутентификация: регистрация с подтверждением email, вход, восстановление пароля, сессии, двухфакторная аутентификация (TOTP) для модераторов/администраторов.
- Публикации: текст + до 4 изображений (с обработкой — сжатие, миниатюры, удаление EXIF/GPS), хештеги, упоминания, ответы, лайки, репосты, закладки, удаление своих постов.
- Лента: вкладки «Подписки» и «Обзор» с курсорной пагинацией, подгрузкой при прокрутке, кнопкой новых записей.
- Профиль: аватар/обложка, био, город, ссылка, подписки/подписчики, вкладки «Публикации», «Ответы», «Медиа».
- Поиск: по пользователям, тексту и хештегам, с фильтрами по теме/городу и нормализацией узбекских апострофов.
- Уведомления: подписка/лайк/ответ/репост/упоминание, с объединением повторных реакций на один пост.
- Блокировки и жалобы: с исключением из персональных лент и запретом взаимодействий.
- Админ-панель: очередь жалоб, скрытие/восстановление публикаций, ограничение/восстановление аккаунтов, назначение ролей, управление темами, статистика, журнал действий.
- Статические страницы: правила сообщества, условия использования, политика конфиденциальности (черновые, требуют юридической проверки перед публичным запуском — см. раздел 13 ТЗ).

## Стек

| Компонент | Технология |
| --- | --- |
| Веб-интерфейс | Next.js 15 + TypeScript + Tailwind CSS |
| Сервер и API | Python + FastAPI |
| База данных | PostgreSQL |
| Rate limiting | Redis |
| Хранение изображений (dev) | MinIO (S3-совместимое) |
| Развёртывание | Docker Compose |

## Структура

```
apps/
  web/   — Next.js фронтенд
  api/   — FastAPI бэкенд, /api/v1
docker-compose.yml
.env.example
```

## Запуск (Docker)

1. Скопировать `.env.example` в `.env` и при необходимости поменять значения:

```bash
cp .env.example .env
```

2. Поднять все сервисы:

```bash
docker compose up --build
```

3. Применить миграции БД (после того как контейнер `api` поднялся):

```bash
docker compose exec api alembic upgrade head
```

Сервисы после запуска:

- Веб: http://localhost:3000
- API: http://localhost:8000 (документация — http://localhost:8000/docs)
- MinIO консоль: http://localhost:9001

## Запуск без Docker (для разработки)

### Backend

```bash
cd apps/api
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

Нужны локально запущенные PostgreSQL и Redis (см. `.env`).

### Frontend

```bash
cd apps/web
npm install
npm run dev
```

Автоматически генерируется FastAPI (OpenAPI) и доступна по адресу `/docs` (Swagger UI) и `/openapi.json` при запущенном backend.

## Резервное копирование БД

```bash
./scripts/backup.sh ./backups        # создать бэкап (pg_dump + gzip), хранит последние 14
./scripts/restore.sh ./backups/yoz_2026-01-01_03-00-00.sql.gz   # восстановить из бэкапа
```

Для ежедневного автоматического бэкапа добавьте `scripts/backup.sh` в cron на хосте, где запущен `docker compose` (пример — в комментарии внутри скрипта).

## Первый администратор

После первого запуска все новые аккаунты получают роль `user`. Чтобы назначить первого администратора, выполните вручную (после `alembic upgrade head`):

```bash
docker compose exec postgres psql -U yoz -d yoz -c "UPDATE users SET role = 'admin' WHERE email = 'you@example.com';"
```

Дальнейшие назначения ролей делаются уже через панель администратора (`/admin`).
